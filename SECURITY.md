# Pelaporan keamanan

Kontak yang diberikan maintainer: **bar.arck90@gmail.com**. Keterkiriman, kepemilikan mailbox, dukungan enkripsi dan waktu respons belum diverifikasi. Jangan menganggap alamat ini kanal aman untuk rahasia.

Kirim ringkasan minimal: versi/revisi paket, aturan atau file terdampak, reproduksi sintetis, dampak yang teramati, serta cara menghubungi pelapor. Jangan kirim token, password, data pengguna, log mentah atau detail target pihak ketiga. Minta kanal aman sebelum berbagi bukti sensitif. Tidak ada SLA respons yang dijanjikan.

Jika kontak gagal, simpan laporan secara lokal dengan akses terbatas dan minta maintainer menyediakan kanal lain; jangan memindahkan rahasia ke issue publik. Issue publik boleh memuat perbaikan dokumentasi non-sensitif setelah ditinjau.

Kebijakan ini bukan otorisasi pentest, safe harbor legal, atau izin mengakses sistem di luar scope. Untuk insiden aplikasi, ikuti kanal pemilik aplikasi; kontak paket skill tidak otomatis memiliki wewenang atas aplikasi itu.
